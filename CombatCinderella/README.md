# Combat Cinderella NPC v0.3

Stardew Valley 1.6 / SMAPI 4.x / Content Patcher 2.x.

## Changes
- Replaced v0.2 character art with new hand-authored native 16×32 pixel sprites.
- 64×128 RGBA sheets; transparent backgrounds; no AI-image downscaling or cutout.
- Four directions and four walk-phase frames per direction.
- Carrie: white officer cap, gold insignia, navy uniform and ponytail.
- Natalica: dark bob, sunglasses, long dark coat.
- Existing portraits, dialogue, schedules, IDs and NPC placement preserved.
- Birthdays set to Spring 28 per supplied reference sheets.

## Installation
Close the game. Remove the old CombatCinderella folder from Mods (keep a backup outside Mods). Extract this archive so Mods/CombatCinderella/manifest.json exists. Start SMAPI.

## Notes
These are native-grid hand-authored first-pass sprites, **not** exact pixel-perfect copies of the supplied reference sheets. Pixel art quality and animation require in-game review. Portraits are carried forward from v0.2. Stardew's vanilla daily talk limit remains.
